# Jarvis backlog

Активный ML-план развития зафиксирован отдельно:
[`ml/JSC_ROADMAP_RU.md`](ml/JSC_ROADMAP_RU.md).

## Согласованный roadmap

### Приоритет 1 — MVP-надежность и полезные функции

- [x] изолировать pytest от реальных движков, сети и аудиоустройств;
- [x] восстанавливать любой упавший/зависший trace в `IDLE`;
- [x] реализовать постоянные напоминания: создать, показать, отменить;
- [x] добавить runtime-диагностику ПК, периферии, CUDA и движков;
- [x] сделать воспроизводимый Lite-установщик с опциональным включением Ollama.
- [x] добавить Jarvis Control Center: запуск/остановка, конфигурация, Doctor,
  голосовая калибровка и live-журнал в едином desktop-интерфейсе;
- [ ] после проверки UX подключить Control Center как основной ярлык и entrypoint
  устанавливаемого `.exe` без ручной установки пакетов.

### Приоритет 2 — персонализация и управление

- [ ] подключить долговременную память к диалогу;
- [x] хранить профили и калибровки вне будущего `.exe`, в `%APPDATA%\Jarvis`;
- [ ] закрепить Ollama и добавить управляемое включение в будущем UI;
- [x] реализовать общий протокол отмены trace, инструментов и stale-результатов.

### Приоритет 3 — голосовое развитие

- [x] добавить индивидуальную калибровку уровня голоса, шума и VAD для каждого
  профиля и микрофона без сохранения сырого аудио;
- [ ] добавить wake word после стабилизации основного runtime;
- [ ] собрать реальную голосовую выборку и только затем снова обучать NLU/STT
  адаптацию.
- [ ] после MVP исследовать идентификацию/верификацию говорящего по тембру
  собственной моделью. Это отдельная opt-in биометрическая функция: не
  смешивать её с акустической калибровкой, не сохранять голосовые образцы без
  явного согласия и предусмотреть запасной ручной выбор профиля.

### Отложено — расширенная калибровка жестового режима

- [ ] добавить голосовой мастер калибровки Gesture Core: выбор камеры,
  проверка кадра и освещения, настройка порога уверенности, числа стабильных
  окон и cooldown без ручного редактирования `config.yaml`;
- [ ] поддержать команды наподобие «откалибруй жесты», «сделай распознавание
  чувствительнее» и «используй другую камеру»;
- [ ] хранить калибровку отдельно для профиля пользователя, камеры и версии
  жестовой модели, не сохраняя видеозаписи без явного согласия.

### Отложено — финальное дообучение NLU после расширения функций

- [ ] завершить дообучение собственной NLU на числах, записанных русскими
  словами. JSC v5 содержит отдельные квоты таких примеров, числовой признак и
  grounding; последний сбалансированный эксперимент дал 77,50% точности
  значения и корректно разобрал «двадцать» в четырёхшаговой команде, но
  production-гейт ещё не достигнут;
- [ ] добавить в корпус разнообразные естественные формулировки всех новых
  возможностей Jarvis и провести regression/holdout-проверки только после
  завершения согласованных функциональных параграфов;
- [ ] не запускать обучение автоматически и не использовать пользовательские
  логи как датасет без отдельного явного согласия.

Напоминания и профиль пользователя хранятся раздельно. Личный текст нельзя
автоматически добавлять в обучающий датасет: только отдельный opt-in экспорт с
анонимизацией.

Установщик остаётся рабочим прототипом, но его публикация, подпись и дизайн
заморожены до завершения возможностей MVP.

## Выполнено: собственная NLU-модель-менеджер

CharCNN обучена с нуля методами `standard`, `augmented` и `curriculum`, прошла
regression и два holdout-гейта и подключена как
`models/nlu_manager_finetuned.pt`.

## Выполнено: изоляция pytest от установленных runtime-движков

**Статус:** pytest по умолчанию принудительно отключает реальные Whisper,
Silero TTS/VAD, Ollama, микрофон и устройство вывода. Тест конкретного real
path обязан явно подставить контролируемый fake.

На чистом компьютере с Python 3.12.9 тестовый запуск дал `114 passed, 4 failed`.
Это не выявило несовместимость Python 3.12: падения появились потому, что часть
тестов случайно использовала реально установленные Whisper, Silero TTS и клиент
Ollama.

Наблюдавшиеся симптомы:

- `tests/test_llm.py::test_plain_reply_path` и
  `test_tool_call_then_response` остановили EventBus раньше, чем завершилась
  попытка подключения к недоступному Ollama;
- `tests/test_main_persistent.py` превысил пятисекундное ожидание во время
  первичного скачивания Whisper Base (139 МБ) и Silero (38,2 МБ);
- `tests/test_main_roundtrip.py::test_own_nlu_routes_reminder_parameters_end_to_end`
  запустил настоящий Silero TTS, не дождался длинной реплики и проверил
  оркестратор в состоянии `SPEAKING`.

Гарантии:

- pytest никогда не обращается к сети, Ollama, микрофону или устройству вывода;
- Whisper, Silero/VAD, Ollama и аудио явно заменяются тестовыми реализациями в
  интеграционных тестах независимо от установленных пакетов;
- один и тот же набор тестов проходит с установленными и отсутствующими
  optional runtime-зависимостями на поддерживаемых версиях Python;
- тестовый запуск не скачивает модели и не воспроизводит звук.
