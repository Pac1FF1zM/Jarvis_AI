# Датасет Jarvis NLU v2

Корпус полностью создан внутри проекта и не содержит внешних датасетов,
предобученных моделей или материалов Hugging Face.

## Состав

| Разбиение | На каждый intent | Всего |
|---|---:|---:|
| `train.jsonl` | 120 | 840 |
| `validation.jsonl` | 30 | 210 |
| `evaluation_holdout.jsonl` | 15 | 105 |

Все семь классов сбалансированы: `get_current_time`, `set_reminder`,
`open_application`, `list_applications`, `cancel`, `general_chat`, `unknown`.
Разбиения используют разные семейства формулировок и не имеют одинаковых
текстов между собой или со встроенным baseline-корпусом.

Особое внимание уделено:

- всем семи приложениям из allow-list, включая Discord и браузер;
- русским и английским названиям, а также наблюдавшимся вариантам Whisper:
  `дисорд`, `дискод`, `дискор`, `пейнт`, `паинт`, `блакнот`;
- вежливым словам, обращению «Джарвис» и разному порядку слов;
- отрицательным контрастам: обсуждение приложения не является его запуском;
- неполным и неразборчивым фразам для безопасного класса `unknown`;
- разным значениям `duration`, `reminder_text` и `application`.

`dataset_manifest.json` содержит количество примеров и SHA-256 каждого файла.
Воспроизвести файлы без сети можно командой:

```powershell
python -m training_workspace.build_dataset
```

Не переносите примеры из validation/evaluation holdout в train после просмотра
метрик. Для следующего цикла добавляйте новые реальные пользовательские фразы
в отдельную версию корпуса.
