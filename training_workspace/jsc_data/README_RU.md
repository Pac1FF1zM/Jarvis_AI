# JSC Dataset v3

Это воспроизводимый синтетический корпус для обучения собственного
семантического ядра Jarvis. Он не содержит данных, весов или токенизаторов
Hugging Face и не создаётся внешним AI API.

## Состав

- `train.jsonl` — 1 400 примеров для оптимизации весов;
- `validation.jsonl` — 290 примеров для выбора конфигурации и early stopping;
- `test.jsonl` — 290 примеров для финального сравнения экспериментов;
- `evaluation_holdout.jsonl` — 210 замороженных синтетических сценариев;

Корпус включает не только время, приложения и напоминания, но и браузер,
пользовательские файлы, окна, Windows/media controls, подтверждение опасных
действий, составные планы и диалоговые исправления.
- `dataset_manifest.json` — квоты, покрытие acts, fingerprint схем инструментов
  и SHA-256 каждого split.

Каждая строка хранит историю диалога, текущую реплику, незавершённое состояние
JAL при его наличии и каноническую целевую программу JAL. Категории включают
одиночные и составные команды, уточнения, исправления, ASR-искажения, hard
negatives и команды вне доступных возможностей (OOD).

## Пересборка и проверка

Из корня проекта:

```powershell
python -m training_workspace.build_jsc_dataset
pytest tests/test_jsc_dataset.py -v
```

Сборка детерминирована. `family_id` вычисляется из хеша диалогового шаблона
после маскирования приложений, сообщений, времени и чисел. Поэтому одинаковая
формулировка с другими slot-значениями не может незаметно попасть и в train, и
в контрольный split. Загрузчик останавливает обучение при неизвестном поле,
дубликате JSON-ключа или входа, неканоническом JAL, несовместимости с реальной
схемой инструмента и пересечении family/input между split’ами.

`evaluation_holdout` остаётся синтетическим и не заменяет будущую закрытую
выборку реальных голосовых команд. Его нельзя использовать для выбора эпохи,
архитектуры, порога уверенности или гиперпараметров.
