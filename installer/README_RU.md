# Установщик Jarvis

Один `Jarvis_Setup.exe` устанавливает **Jarvis Lite** без системного Python и
ручных PowerShell-команд. Необязательная галочка добавляет **Jarvis Full**:
нативное приложение Ollama и `qwen2.5:7b-instruct`.

## Что входит в Lite

- изолированный Python 3.12.9 внутри папки Jarvis;
- собственная NLU и безопасные инструменты;
- Parakeet Transformers runtime, Silero TTS, VAD и push-to-talk;
- основной Control Center, память, рабочие пространства и вкладка жестов;
- ограниченная тестовая gesture-модель G01-G06;
- приложения, время и постоянные напоминания;
- пользовательские данные в `%APPDATA%\Jarvis`;
- автоматический Runtime Doctor после установки.

Lite требует интернет во время установки зависимостей. Pinned-модель Parakeet
имеет отдельный обязательный этап просмотра и принятия CC-BY-4.0 через
`SETUP_PARAKEET.cmd`; её веса не включаются в Setup. Установщик
сам выбирает PyTorch CUDA для обнаруженной NVIDIA или CPU-вариант. Драйвер
видеокарты он не изменяет.

Ярлык «Jarvis» открывает Control Center. Консольный runtime запускается и
останавливается кнопками внутри приложения.

## Jarvis Full / Ollama

Галочка Full по умолчанию снята. Её можно выбрать сразу либо позже запустить
ярлык «Включить Jarvis Full (Ollama)». Ollama устанавливается в профиль
Windows, запускается локально и загружает выбранную модель. Эта ветка требует
несколько дополнительных гигабайт и может работать медленно на 8 ГБ RAM.

## Сборка

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\installer\BUILD_INSTALLER.ps1
```

Build-скрипт скачивает строго Python 3.12.9 с закреплённым SHA-256, проверяет
его Authenticode-подпись, при необходимости ставит локальную копию Inno Setup
6.7.3 с проверкой издателя и создаёт:

```text
installer\output\Jarvis_Setup.exe
```

`cache/`, `.tools/` и `output/` не попадают в Git. Сборка сообщает SHA-256.

## Важное ограничение публикации

Сейчас итоговый Setup не подписан сертификатом владельца Jarvis, поэтому
SmartScreen может показать предупреждение. Для публичного релиза нужен
отдельный Windows code-signing certificate и подпись Setup после сборки.
Зависимости и модели также пока загружаются из интернета — полный офлайн-пакет
будет отдельным крупным артефактом.
