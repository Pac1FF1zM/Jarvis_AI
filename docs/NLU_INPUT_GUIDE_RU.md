# Что нужно от владельца Jarvis для дообучения NLU

## Обязательные решения

1. Список действий, которые Jarvis вообще разрешено понимать. Для каждого:
   canonical intent, обязательные slots и нужен ли запрос подтверждения.
2. Список основных приложений и пользовательских названий: например,
   `Visual Studio Code -> VS Code, вижуал студио код, вскод`.
3. Политика неоднозначности: Jarvis уточняет, игнорирует или предлагает варианты.
4. Политика незаконченной речи: составная команда фиксируется только после конца
   всей фразы; до этого ни первое, ни последующие действия не выполняются.
5. Разрешение на локальное сохранение диагностических текстов. Аудио можно не
   сохранять; для первой итерации достаточно обезличенного JSON из live-теста.

## Подтверждено владельцем 2026-08-13

- `visual_studio_code`: Visual Studio Code, VS Code, вижуал студио код,
  висуал студио код, ваэс код, вэс код, код;
- `telegram`: Telegram, телеграм, телега;
- `discord`: Discord, дискорд, дискорт, дискот;
- незаконченная фраза ничего не выполняет;
- составная команда ожидает конца всей фразы;
- самокоррекция отменяет предыдущую часть;
- неоднозначное приложение требует уточнения;
- цитаты, вопросы о командах и фоновая речь ничего не выполняют.

## Минимальные примеры от владельца

Подготовьте естественные фразы, а не студийный датасет:

- 20 обычных команд, которыми вы реально пользуетесь;
- 10 составных команд;
- 10 брошенных или исправленных фраз;
- 10 отрицаний, вопросов о командах и цитат;
- 10 команд с русско-английскими названиями приложений;
- 10 фраз, которые Jarvis точно не должен выполнять.

Говорите их через `TEST_PARAKEET_NLU.cmd --mic`. Аудиофайлы отдельно создавать
не требуется. Скопируйте JSON-результаты в один текстовый файл и рядом для
ошибочных строк укажите только:

```text
Что я имел в виду: запустить Visual Studio Code
Правильные действия: open_application(application=visual_studio_code)
Нужно ли было ждать/уточнить: нет
```

Если мысль была брошена, правильная пометка:

```text
Правильные действия: []
Нужно ли было ждать/уточнить: ждать, затем ничего не выполнять
```

Не исправляйте STT-текст внутри JSON: исходная ошибка распознавания нужна для
обучения устойчивости NLU.
