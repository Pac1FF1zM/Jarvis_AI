# JSC Voice Collection v1

Всего: **195 произнесённых реплик**. Цель — собрать реальные
Parakeet-транскрипции и результаты production NLU/router
для следующего JSC. Произносите только текст после идентификатора, сам ID не
произносите. Идите строго по порядку: тогда строка лога однозначно сопоставится
с эталоном.

## Перед началом

1. Запустите Jarvis через `START_JARVIS_UI.cmd`.
2. Дождитесь `JARVIS_RUNTIME_READY`.
3. Начните новую сессию перед этим сценарием и не вводите параллельно текстовые
   команды.
4. Между командами выдерживайте 2–3 секунды и дожидайтесь ответа Jarvis.
5. Если распознавание явно оборвалось, не повторяйте команду сразу: переходите
   дальше. Ошибка нужна в логе.
6. Для multi-turn произнесите обе реплики одной группы подряд.
7. После завершения пришлите самый свежий файл из `logs/sessions/`. Полный звук
   не обязателен; если сохраните WAV отдельно, назовите его ID команды.
8. Также пришлите `logs/jsc_shadow.jsonl`: там находится параллельный ответ JSC,
   который не исполнялся и не мог повлиять на действия Jarvis.

Команды удаления файлов, выключения компьютера и блокировки намеренно не входят
в сценарий. Напоминания можно удалить после теста через интерфейс.

## После записи

Пришлите:

- последний `logs/sessions/jarvis_session_*.txt`;
- `logs/jsc_shadow.jsonl`;
- приблизительные ID, на которых Jarvis сделал явно не то действие;
- при наличии — WAV только для особенно плохих распознаваний.

Не редактируйте лог: в нём нужны исходные `TRANSCRIPTION_READY`, `NLU_RESULT`,
`TOOL_CALL`, `TOOL_PLAN` и финальный результат с общим `trace`.
